# 01 产品需求 PRD

版本 HL-DOC-1.0.0，FROZEN。需求对象是教学与实验系统，不是实际在线电商平台。

## 1. 目标和用户

目标：用可复现的 Hadoop 数据处理链路回答“销售来自哪里、客户如何分层、推荐哪些商品”，并完成 ALS 与神经协同过滤模型训练、推荐质量比较和 CUDA 加速实验。

用户角色：分析人员（查看运营与客户）；实验人员（通过受控 CLI 运行数据/模型任务并查看实验）；答辩评审（复核来源、作业证据、结果和局限）。1.0 本机单用户演示，不做消费者账号系统，不承诺商业推荐效果。

成功条件：真实数据跑通全链路；金额与计数可手算核验；YARN 上有业务作业证据；四算法在相同协议下有可比较指标；真实 GPU 完成 NCF 训练；页面能查询一致批次结果；数据、模型、版本和原始来源能反向追溯。

## 2. 功能需求

| ID | 必须实现的行为 | 验收结果 |
|---|---|---|
| FR-01 | 导入 UCI 原始 XLSX、计算 hash、归档 HDFS、重复文件幂等 | 批次与源行可追溯，原始文件不改写 |
| FR-02 | 数据规范化、正向/退货/异常分类、缺失与重复疑似统计 | 质量守恒、原因可解释、不把退货全删除 |
| FR-03 | 按日/月/国家/商品统计金额、订单、数量和榜单 | 口径一致、支持日期/国家筛选 |
| FR-04 | 为有效实名标识客户计算 RFM 与规则分层 | 日期基准、去重订单数与分层规则明确 |
| FR-05 | 基于订单内共现构建相似商品 Top10 | 提供共现次数、相似度与搭配解释 |
| FR-06 | POP、ItemCF、隐式 ALS、NCF 均产生客户 Top10 | 候选合法、去重、过滤历史已购、兜底 |
| FR-07 | NCF 完成 GPU 训练及同配置 CPU/GPU 性能实验 | 真实设备证据、同步计时、质量指标与损失曲线 |
| FR-08 | 按冻结时间切分进行四算法离线评价 | Recall/Precision/NDCG/Coverage、冷启动与样本规模齐全 |
| FR-09 | 分析、推荐和模型统一形成不可变 release | 校验后原子切换，失败不影响当前版本，可回滚 |
| FR-10 | 通过只读 API 与 Streamlit 展示结果 | 七类页面、版本固定、空态及错误正确 |
| FR-11 | 记录任务状态、错误、耗时与资源信息 | application ID、run/model/release 关联可查 |
| FR-12 | 提供可重复部署、恢复、数据说明和实验报告 | 环境锁、数据出处、验收证据可重现 |

## 3. 页面范围

必做七页：总览、销售分析、客户分层、商品关联、客户推荐、模型实验、数据质量与任务。无发布版本时页面显示引导与空态，不制造示例结果冒充真实运行。CLI 是唯一离线写入入口；网页不提供上传、训练、发布、删除、SQL 或 shell 执行按钮。

## 4. 非功能需求

| ID | 约束 | 量化或判定方式 |
|---|---|---|
| NF-01 | 正确性与一致性 | 金额精确到便士；跨页面同 release；计数守恒通过 |
| NF-02 | 查询性能 | 全量基准数据发布后，本机 5 并发下只读列表/推荐 P95≤2秒、错误率<1%；不含初次进程启动 |
| NF-03 | 资源适配 | 约 7.4GiB WSL 下任务串行重计算；训练无 OOM，实际峰值记录 |
| NF-04 | 可复现 | 固定数据 hash、代码、配置、种子与环境；排序确定；GPU差异有说明 |
| NF-05 | 可运维 | 失败重试不重复发布/累加；备份恢复演练通过 |
| NF-06 | 本机安全 | API/UI 仅回环监听；只读数据库账号；凭据不入 Git/日志 |
| NF-07 | 可观测 | 任务 ID、版本、日志、错误和运行时间可关联 |
| NF-08 | 可审计文档 | 每项需求有设计、开发任务、测试与运行证据映射 |

NF-02 性能是待测门槛，文档不填造达标值。MapReduce/Spark/GPU 训练耗时只要求记录和比较，不规定一定更快或在某分钟内完成。

## 5. 明确不做

生产级登录权限、多租户、交易支付、实时点击流、网页训练任务管理、爬取微博、GNN、语义搜索、HBase、Elasticsearch、Kafka、多机容错或分布式 GPU 训练均不在 1.0。公开数据不含真实浏览/点击、正式商品类别，禁止推导转化率或将规则标签描述为真实流失预测。

## 6. 交付定义

实现阶段交付完整仓库、依赖锁、数据来源和清洗报告、MapReduce JAR、四算法产物、GPU训练/对照证据、数据库迁移、API契约校验、页面、自动化测试与答辩报告。当前阶段仅交付其冻结设计文档，不包含上述实现。

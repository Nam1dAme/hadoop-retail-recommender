## 验证与兼容

1. 7项实验数据/指标单测通过，覆盖日期边界、订单不能跨窗、映射隔离、匿名热门、冷启动、共同 cohort、短列表指标、稳定分块及验证选参。
2. Java LocalJobRunner 窗口测试确认2011-09-01及其后记录不进入 TRAIN 篮子和交互；此前完整回归94项通过。
3. 准备器逐对比对162,426条独立 TRAIN 交互与 YARN 结果。
4. 独立验收器从 clean SALE 重新构建 EVAL/FULLFIT 映射、不同订单计数、最后购买日期、含匿名热门、未来相关标签、冷启动和排除计数；全部一致。五个应用身份、成功状态、文件 hash、schema 及源码快照通过。
5. 成功批次现在可在显式关联 experiment 的前提下创建后续任务；隔离 MariaDB 测试通过。批次状态和已成功质量数据保持不可变，未新增数据库迁移或权限。

首次实测发现旧 create_task 仅允许 PROCESSING 批次，在提交任务前被控制层拒绝。修复后沿用同一 experiment，五个应用和准备任务均为 attempt=1；未重置成功批次。W06 另有真实子进程、四算法保存加载和 CUDA 训练验收，进度由对应记录说明。

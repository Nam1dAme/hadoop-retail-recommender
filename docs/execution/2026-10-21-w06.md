## 实现与参数

| 模块 | 职责 |
|---|---|
| ml/models.py | POP规则、最近20商品种子的ItemCF、Spark隐式ALS、分块因子评分与保存加载 |
| ml/ncf.py | 固定NeuMF、CUDA FP32训练、验证早停、可信state_dict及映射校验 |
| ml/sampling.py | 每个TRAIN正例每轮4个均匀有放回负例，seed+epoch固定样本与批次顺序 |

| orchestration/training.py、ml/worker.py | 父进程逻辑锁/心跳、串行训练子进程、不可变模型包、验证冻结与TEST封存 |
| scripts/verify-w06.py | 独立核对八个模型、Spark实际参数、CUDA图/历史、全部负样本及封存关联 |

ALS实际为 Spark3.5.7、Java1.8.0_504、local[2]、driver2GiB、shuffle partitions4；implicitPrefs/nonnegative均true，rating=log(1+c_ui)，alpha10、maxIter10、seed42。NCF为GMF16与MLP32→64→32→16融合，BCEWithLogitsLoss、Adam、weight_decay=1e-5、batch1024、FP32、关闭AMP/TF32，最多20轮、验证WARM NDCG连续3轮无>1e-6提升早停。

八个成功候选均对应已提交源码 `2da8289`，模型映射 SHA-256统一为 `b75efe168e2d2b48b56844fc4c7fa287d7068ec3f49bac86ef20657a04d4e672`，环境锁为 `48eee008149d7925d592b530d8629420ac3993eec3becc0013db0e1c0128dbac`。Python3.12.3、NumPy1.26.4、PyTorch2.6.0+cu124；85个已安装包的依赖兼容检查通过。

## 测试、修复与可追溯性

最终完整回归 86 passed / 0 failed / 0 skipped，JUnit 为 `var/w04/pytest-final.xml`。Java LocalJobRunner 手算覆盖冻结 T-04/05/06、空相似度结果、102 种商品的确定截断、相似度公式、订单冲突和 int64 溢出；隔离真实 MariaDB 测试覆盖恢复、复用、失锁与篡改。synthetic 用于隔离测试，正式 YARN 证据来自上表的十二个真实业务应用。

首次实测发现长 SQL 验算会推迟心跳，观测到最大心跳年龄约 49 秒；进程和句柄仍活，未按超时重启。`dcbf20b` 补上 SQLite 进度回调，在长语句内部持续检查逻辑锁并更新心跳，失锁时中断并保留原异常；对应真实 SQL 测试和整链隔离测试已通过。`8a5cf21` 补强上游引用、参数 schema、环境/源码关联及 W03 金额/数量零容差对账。成功 HDFS 产物保持不可变。补修后的真实独立验算记录 89,660 次回调，最大回调间隔 2.432 秒、最大锁检查间隔 4.394 秒；两组数据分别描述首轮任务心跳年龄与补修后验算的回调、锁检查间隔。

正式业务执行于已提交的 `e0e280b`，所有 W04 manifest 的 code_dirty=false，源码快照逐项对应该 commit；实现源自 `df34003`。修复后的验算器另行复核原产物，首次执行和后续复核的版本均在最终验收 JSON 中记录，可通过各自 commit 与 SHA-256 追溯。

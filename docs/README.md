## 已冻结的主要决定

- UCI Online Retail 为唯一真实实验数据；HDFS 存储，Java MapReduce 在 YARN 上做核心清洗、聚合、RFM 和共现计算。
- 四种推荐方法全部交付：POP、ItemCF、Spark 隐式 ALS、PyTorch NCF（NeuMF）。NCF GPU 训练和 CPU/GPU 对照属于最终验收范围。
- Spark 只用于 ALS，以单机 local[2] 执行；NCF 为单机单 GPU；不宣称 GPU 加速 Hadoop，不宣称多机分布式训练。
- MariaDB 为结果与控制库；FastAPI 提供只读接口；Streamlit 通过接口展示。离线任务由 CLI 发起，不在网页执行训练。
- 严格按时间划分评价数据；评估模型和全量服务模型分开，模型不优于简单方法也必须如实报告。
- 用不可变 release 将分析、推荐、模型版本绑定，原子切换当前 release，页面跨请求显式固定 release。

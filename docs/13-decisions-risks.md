# 13 架构决策、风险与事实待验证项

版本 HL-DOC-1.0.0，FROZEN。

## 1. 架构决策记录

| ADR | 决策 | 原因、代价与替代方案 |
|---|---|---|
| ADR-01 | 用公开零售数据替代电影/微博业务 | 交易来源稳定、可核验；不复制复杂社交爬虫；代价是没有社交图/显式评分 |
| ADR-02 | 核心ETL/统计用Java MapReduce on YARN | 体现Hadoop实质计算、沿用Java8/Maven；比全Python慢开发，但不能以pandas替代全部业务作业 |
| ADR-03 | ALS与NCF均必做 | 同时覆盖模型训练和神经网络；POP/ItemCF为必要对照；代价是四方法维护与统一评价 |
| ADR-04 | Spark只跑ALS、NCF单GPU | 资源有限，分开承担CPU因子分解和GPU神经训练；不采用多机训练/GPU调度进YARN |
| ADR-05 | FastAPI只读 + Streamlit | 页面与数据契约可独立验证，免去Vue/SpringBoot双栈；新增API进程开销可控 |
| ADR-06 | MariaDB作为结果/控制库 | 实机已有10.11；关系约束与原子指针易维护；不额外安装HBase/ES/Kafka |
| ADR-07 | 整数便士、来源本地日期 | 防金额误差和不可靠时区转换；不能映射到北京时间做真实时段分析 |
| ADR-08 | EVAL与FULLFIT分开 | 时间评价不泄漏、展示可使用全部历史；需要双份映射/模型和明确标签 |
| ADR-09 | 不可变release + current单例 | 支持原子发布/回滚/跨页一致性；存储冗余但课程规模可接受 |
| ADR-10 | 正式NCF用FP32，AMP可选实验 | CPU/GPU比较容易解释、避免硬件精度支持差异；牺牲部分速度 |
| ADR-11 | 共现篮子100上限、co_count≥3 | 防批发超大篮子平方膨胀和低频噪声；有偏差必须报告，不能隐藏截断 |
| ADR-12 | 1.0只做本机单用户 | 认证/公网发布范围明确；未来对外服务必须另行设计，不可直接开放端口 |

## 2. 风险登记

| 风险 | 影响与触发 | 缓解与责任任务 |
|---|---|---|
| RK-01 GPU不可见/驱动过旧 | NCF CUDA验收阻塞 | W01采普通WSL/Windows证据；W06可CPU调试但G-GPU不能跳过 |
| RK-02 GPU架构不被cu124构建支持 | 版本基线无法运行 | W01核对compute capability与wheel，按00版本变更，不填假设备 |
| RK-03 内存不足 | Spark/MR/NCF互相挤占 | W01预算，串行重任务、评分分块、监控RSS；必要时记录资源变更 |
| RK-04 宿主磁盘不足 | venv下载/临时产物失败、VHDX膨胀 | W01先查VHDX与15GiB预算；未过门禁不扩数据 |
| RK-05 真实数据缺失/取消/批发 | 金额与模型偏差 | W03审计分类守恒，W04篮子截断披露，样例手算 |
| RK-06 神经模型不优于热门 | 预期效果不成立 | W05时间评价；如实报告，默认算法按验证选择，不改变TEST |
| RK-07 数据泄漏 | 指标虚高 | W05训练窗口先过滤，共同候选；独立EVAL/FULLFIT hash |
| RK-08 查询混版本 | 金额与推荐来源不同 | W08不可变release；W10跨请求固定ID |
| RK-09 依赖与旧版本兼容 | PySpark/Python/Java或CUDA失败 | W01锁依赖、跑ALS和GPU真冒烟；不盲升最新 |
| RK-10 源数据重复行误删 | 营业金额变化 | W03仅报告疑似重复，保留；文件级幂等 |
| RK-11 子任务失联重复执行 | 资源耗尽、重复写入 | W02/W08活句柄与锁、唯一键、新attempt目录 |
| RK-12 人为描述夸大 | 把单机/合成当真实大集群 | W11报告必须区分物理拓扑、数据性质、实验用途与未知项 |

## 3. 允许待采集的环境事实

| 事实 | 当前证据 | 后续收集/门禁 |
|---|---|---|
| GPU型号、显存、compute capability | 本会话无法访问设备 | 普通WSL与Windows nvidia-smi、torch设备查询；G-ENV |
| Windows NVIDIA驱动 | 未核实 | 不根据NVML受限错误断言版本；G-ENV |
| PyTorch/PySpark等依赖 | 当前未安装 | W01完成解析锁与真冒烟；G-ENV |
| HDFS/YARN/MariaDB运行状态 | 隔离进程视图不足 | 普通WSL端口/jps/YARN/DB连接实测；G-ENV |
| VHDX真实宿主盘 | 未核实，C剩余约14GiB | 宿主盘空间预算；扩数据前必做 |
| 训练耗时/指标/API性能 | 尚无业务实现 | W06/W07/W11实测，不在基线伪填数值 |

这些不是未决业务设计：相应检查方法、失败语义和验收门槛已经冻结。文档交付不依赖现在获取GPU权限；最终实现验收依赖真实证据。
